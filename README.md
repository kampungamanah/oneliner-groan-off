# oneliner-groan-off

## Entry

One original dad joke, told at the dinner table: a suitcase that takes "emotional baggage" far too literally.

`main.ts` writes it to `/output/entry.txt`:

> I told my suitcase there'd be no holiday this year. It's still carrying the emotional baggage.

## How to run

The entry lands in `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set, otherwise in `/output/entry.txt`.
